# Models

The existing `RegularNode.f3d`, `TopCenterNode.f3d`, `TopLeftNode.f3d` and
`TopRightNode.f3d` files are the Chromance lighting-node designs.

[ESP32 enclosure](ESP32Enclosure/) contains a separate parametric under-desk
controller enclosure, preserved design revisions, STEP solids for Fusion, 3MF
print meshes, geometry previews, hardware notes and a reproducible Python CAD
environment.

The current ESP32 enclosure also includes a [SolidCraft project](ESP32Enclosure/solidcraft/README.md)
with the assembled model, individual parts and quick fit prints.
